# Line1 / Line2 修复进展（2026-08-12）

## 本轮目标

针对用户检查指出的四类阻断问题修复现有 Web 版本：机械臂不动作、物体脱离机械臂自动移动/穿模、底座安装高度错误、Line2 新资产比例方向错误且相互重叠。Line3 已记录为放弃状态，本轮不再修复。

## 根因与决定

1. 12 个 MJCF 均显式禁用接触且重力为零；所有业务物体均为 `worldbody` 静态 geom。
2. Panda 安装 Z 约为 0.13–0.15 m，而主台面约为 0.58–0.775 m。
3. Line2 GLB 是独立 Three.js overlay，没有读取 MuJoCo 位姿；RoboTwin 资源采用 glTF Y-up，旧代码直接当作 Z-up；手工实例 scale 叠加了错误的大比例。
4. 旧播放只是无任务语义的 actuator 正弦波，且业务物体没有 custody/hand body 绑定。

选择保留 MuJoCo 为唯一物理真值：动态 `task_payload` 存在于 MJCF，Line2 可视 GLB 只跟随该 body；动作由确定性关键帧驱动，每个场景所有机械臂都有连续的非静态轨迹，物体仅在夹取—交接—释放窗口跟随 Panda hand。

## 已完成

- 12/12 场景恢复接触和重力。
- 12/12 场景 Panda 安装面与主台面齐平，落地支撑柱同步加高。
- 12/12 场景新增自由刚体 `task_payload`，替换同位置静态代理。
- 8 个 RoboTwin GLB 写入来源比例与 Y-up 元数据；运行时完成 Z-up 校正与 bottom-center 归一化。
- 6/6 Line2 场景各有一个可见真实物体绑定 MuJoCo payload。
- 12/12 场景建立 16 秒多臂动作程序，替换旧正弦预览。
- 通过 MuJoCo 前向运动学逐场景选择可达抓取臂并离线校准抓取位姿；12 个主抓取点中 11 个误差小于 1 cm，Line1 Demo03 为 3.6 cm。
- Line2 药房主任务物体由不可达的 A2 瓶调整为靠近四号臂的 A1 药盒，保留 A2 作为药品货架物料。
- 隐藏全部已由 RoboTwin GLB 替代的 primitive 视觉代理，保留其静态碰撞几何，消除重影且不牺牲工装碰撞。
- 修正初始 Line1 页面误报“正在初始化 Line2 场景”的状态文案。
