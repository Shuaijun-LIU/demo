# 六场景 Franka Panda 工位 Alpha

这是视觉优先调整后的首个完整场景里程碑，用于先检查空间构型，再继续任务闭环。

## 已接通

- MuJoCo Menagerie 的真实 Franka Panda MJCF 与本地网格资产。
- Demo 01：三臂精密元器件检测与上料工位。
- Demo 02：四臂汽车低压线束布线板。
- Demo 03：三臂食品多规格装盒与称重线。
- Demo 04：四臂大型构件协同装配岛。
- Demo 05：三臂智能药房错拣纠正工作站。
- Demo 06：三臂岭南果品分选去核复作业线。
- WebGL 轨道相机、播放、暂停、复位和按实际臂数生成的关节运动预览。
- MuJoCo Z-up、相机 up 向量和地面网格已经统一，桌体水平且机械臂基座竖直。

## 可检查产物

- `demo01-workcell.png` … `demo06-workcell.png`：相同观察角度下的六套完整工位截图。
- `demo01-three-franka.png`：修正坐标系之前的原始截图，保留用于对比。
- `demo01-three-franka-motion.png`：早期关节运动预览记录。

## 本地运行

~~~bash
npm run dev
~~~

浏览器访问终端输出的 `/demo/` 地址。

## 当前边界

这次优先完成六套机械臂、物料和工装的组合。运动目前是独立关节预览，还没有接入物料抓取、跨臂交接和故障恢复轨迹；这些将在场景构型反馈后继续。
