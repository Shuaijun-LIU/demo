# Demo 01 三臂场景 Alpha

这是视觉优先调整后的第一份可运行场景，用于先检查空间构型，再继续任务闭环。

## 已接通

- MuJoCo Menagerie 的真实 Franka Panda MJCF 与本地网格资产。
- 三台独立 Panda：Arm 1 上料、Arm 2 双面检测、Arm 3 测试分拣。
- 中央工位、混料输送线、P1–P5、交接区、双面相机、功能测试台。
- A、B、NG 三类分流位。
- WebGL 轨道相机、播放、暂停、复位和三组关节运动预览。

## 可检查产物

- demo01-three-franka.png：静止场景。
- demo01-three-franka-motion.png：播放约三秒后的机械臂姿态。

## 本地运行

~~~bash
npm run dev -- --host 127.0.0.1 --port 4173
~~~

浏览器访问 http://127.0.0.1:4173/ 。

## 当前边界

这次优先完成机械臂、物料和工装的组合。运动目前是独立关节预览，还没有接入 P1–P5 的抓取、交接和分拣轨迹；这些将在场景构型反馈后继续。
